# Как внести вклад в проект

Спасибо за интерес к **Индикатору сложности расписания**!  
Любая помощь приветствуется: сообщения об ошибках, идеи по улучшению, исправления и новый код.

## 🐞 Сообщить об ошибке

1. Проверьте, нет ли уже похожего issue в разделе [Issues](../../issues).
2. Если нет — создайте новое issue и выберите шаблон «Сообщить об ошибке».
3. Опишите:
   - что вы делали;
   - что ожидали увидеть;
   - что произошло на самом деле;
   - браузер и устройство (например, Chrome 126 на Windows 11, Safari на iPhone 15).

## 💡 Предложить идею

Создайте issue с меткой `enhancement` и опишите:
- какую проблему решает идея;
- как вы её видите в интерфейсе;
- есть ли примеры в других приложениях.

## 🛠️ Отправить изменения

1. Сделайте форк репозитория.
2. Создайте ветку с понятным названием:
   ```bash
   git checkout -b feature/учёт-праздников
‌
3. Внесите изменения. Постарайтесь сохранить стиль кода и не ломать существующие функции.
4. Проверьте, что проект открывается и работает локально (см. README).
5. Сделайте коммит с осмысленным сообщением:
git commit -m "Добавлен учёт праздничных дней"
6. Отправьте ветку в свой форк и откройте pull request.
7. Опишите в PR, что изменилось и зачем. Если PR связан с issue — укажите Closes #12.
